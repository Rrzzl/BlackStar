## 0. Purpose

This document specifies how Black Star's story, factions, and quests work as a **sandbox** — not a linear main quest gated by acts. The game drops the player into a living galaxy where every faction pursues its own agenda. Story and progression are available through faction questlines the player can engage with, ignore, or actively oppose. There is no forced main quest blocking player freedom.

The reference is **Kenshi** + **Mount & Blade** (sandbox with embedded story) delivered through **Dark Souls** atmospherics (environmental storytelling, lore-through-items, minimal cutscenes). The anti-pattern is a JRPG-style main quest that locks other activities until Act N.

---

## 1. Design principles

1. **The story exists; the player chooses to find it.** The Unmaking mystery and the Hollow Fleet are real, active forces in the world. A player who never talks to a single quest-giver will still see Hollow Fleet ships hunt voidrunners, Verdant Church fleets move on ruins, and Iron Concord patrols shift over time. The mystery is the weather.
2. **Factions have goals, not quests.** A faction's behavior is driven by its **current operations** — long-running AI-driven projects (building a fleet, conquering a sector, recovering an artifact). Quests are **offers to help** one of those operations.
3. **Helping a quest helps the faction.** Every completed quest nudges a real-world outcome. Complete enough Iron Concord fleet-scouting missions and the Concord launches an actual offensive you'll see on the galaxy map.
4. **Every faction has a through-line.** Each has one multi-stage questline that, if followed to completion, reshapes the galaxy. These are the 5–6 "ending paths" of the game. But none are forced.
5. **Reputation has teeth.** Being friendly with faction A often means hostile with faction B. A player cannot max every reputation meter; choices close doors.
6. **The main mystery is opt-in infrastructure, not a main quest.** The Unmaking / Hollow Fleet / First Ones truth is revealed through **discoverable pieces** scattered across the world. Collecting them unlocks endgame access. A player who ignores the mystery never fights the endgame boss — and that is OK; they can end the game by founding their own empire or retiring wealthy.

## 2. Faction state model

Each faction has a runtime state object that advances every in-game day:

```
Faction {
    id: FactionID
    name: string
    aesthetic: Theme              // from narrative bible
    ideology: TextKey

    // Dynamic state
    territory: Set[SystemID]      // systems they control
    influence: Map[SystemID, int] // soft control in other systems
    treasury: int                  // credits
    military: int                  // force rating
    economy: int                   // income rating
    morale: int                    // -100 to 100

    // Relationships
    standing_with_player: int      // -100 (kill on sight) to 100 (fanatical ally)
    standing_with_others: Map[FactionID, int]

    // Long-term projects
    operations: List[Operation]
    completed_operations: List[Operation]

    // Narrative
    main_questline: QuestlineState
    questline_stage: int
}
```

**Operations** are what the faction is trying to do right now. Examples:

- *Iron Concord:* "Reclaim the Kepler arc" (build a fleet, defeat local pirates, annex 3 systems)
- *Verdant Church:* "Consecrate the Kepler-7b ruin" (send pilgrims, block voidrunner access, build a temple)
- *Hollow Fleet:* (hostile) "Destroy all voidrunners near Lattice sites"
- *Scrapfather Syndicate:* "Corner the nullbloom market" (assassinate competitors, monopolize supply)
- *Free Worlds Congress:* "Stabilize the Grayline Treaty" (defuse crises, fund trade, prevent war with Concord)

Each operation has **stages**. Each stage has **offered quests** the player can take to advance it. Completing all stages triggers a faction-wide event: a successful operation reshapes the galaxy map, treasury, military, and relationships.

## 3. Questline types

### 3.1 Faction operation quests (dynamic)

Generated by factions as they pursue operations. These are the **bread and butter** of the quest system.

- Scout this system (faction has an operation needing intel)
- Deliver these supplies (faction operation needs logistics)
- Kill this rival (faction operation needs a rival eliminated)
- Defend this convoy (faction operation needs protection)
- Recover this artifact (faction operation needs a specific item)
- Negotiate this deal (faction operation needs diplomatic cover)

Each is hand-templated with procedural parameters (target system, target NPC, reward scaled to current player level). Writing team creates ~6 templates per faction per operation stage, giving ~300 base quest templates at launch. Each template reuses across multiple playthroughs because targets/rewards rotate.

### 3.2 Faction through-line quests (hand-authored)

Each major faction has a **5–8 stage main questline** hand-authored by the narrative team. These are the "story paths" of the game. Finishing one triggers an ending beat and reshapes the galaxy for the next playthrough / new game+.

- **Iron Concord through-line**: rise through the ranks, uncover internal rot, choose to reform from within or tear it down.
- **Free Worlds through-line**: navigate parliamentary intrigue, broker or break the Grayline Treaty, lead the Congress into a new era.
- **Verdant Church through-line**: begin as a skeptic, uncover the truth about the First Ones, either embrace or reject the faith.
- **Scrapfather through-line**: get close to the Scrapfather's circle, learn their identity, choose to expose, replace, or join them.
- **Homesteaders through-line**: defend a growing colony from all sides, build the galaxy's first genuinely decent new society.
- **Hollow Fleet through-line** (locked by mystery progression): contact the fleet, learn what they truly are, become their herald or destroy them.

Each through-line is **5–8 missions**, each **30–60 minutes**, for a total of ~3–6 hours per faction questline. A player pursuing two factions might spend 10 hours on story. A player ignoring factions might spend 0 hours on story.

### 3.3 The central mystery (discoverable)

The Unmaking / First Ones / Hollow Fleet truth is **not a quest**. It is a set of ~30 **discoverable revelations** found by:

- Reading lore fragments in First One ruins (dungeons)
- Triggering specific voidsmith inspections of recovered artifacts
- Certain faction through-line stages
- Rare static events (fixed coordinates — the same for every playthrough, but each is a small set piece)
- Companion loyalty reveals (Dr. Lilit Veir and The Witness each unlock pieces)

Collecting ≥15 revelations unlocks a **codex entry** labeled "The Truth" that reveals the full story. Collecting ≥20 unlocks **endgame access** — a final Lattice coordinate and the endgame encounter. A player who never finds the mystery never unlocks endgame; they end their playthrough in the normal sandbox state.

### 3.4 Side quests and rumor chains

Hand-authored stand-alone quests that exist outside faction operations. Found at taverns, bounty boards, NPC conversations. Scale targets: 60+ side quests at launch, averaging 15–45 minutes each.

## 4. Quest offer and acceptance flow

### 4.1 How quests surface

Quests appear to the player from several channels:

- **Mission boards** at stations and outposts (standard approach).
- **NPC dialogue** — ambient and named NPCs can offer quests tied to current faction operations.
- **Rumor system** — overheard in bars; the player can investigate or ignore.
- **Broadcast signals** — wide-broadcast faction requests, heard anywhere in a sector.
- **Companion suggestions** — recruited companions flag quests tied to their faction or history.

A quest never *forces itself*. The player can ignore every channel and the game continues.

### 4.2 Acceptance

Accepting a quest opens a journal entry with:

- Quest giver
- Objectives (1–4)
- Rewards (credits, rep, items)
- Consequences summary ("This will improve Iron Concord standing by +8 and reduce Free Worlds by -3")
- Optional "Secret cost" hint if the quest has hidden consequences

The player can always abandon a quest. Abandoning a faction quest incurs a rep penalty with that faction.

## 5. Reputation mechanics

### 5.1 Reputation ranges

Each faction has a reputation number from -100 to +100, mapped to tiers:

| Range | Tier | Effects |
|---|---|---|
| -100 to -50 | Nemesis | Kill-on-sight in their territory, bounty on the player |
| -49 to -20 | Hostile | Hostile at stations, refused service, spawned ambushes |
| -19 to 19 | Neutral | Standard prices and services |
| 20 to 49 | Friendly | 10% discount, mission access, faction-specific gear |
| 50 to 79 | Allied | 20% discount, special missions, T2 faction ships available |
| 80 to 100 | Hero | 30% discount, endgame content, leadership options |

Players generally settle into **2–3 "friendly or better" factions and 2–3 hostile or worse**. Being fully neutral with everyone is possible but dull and closes off most story content.

### 5.2 Rep changes

Rep shifts come from:

- Completing quests (+)
- Hostile actions — killing their ships, stealing from them (−)
- Faction standing contagion — helping a faction's ally gives small rep with that ally
- Broadcast Tower operations (see outposts.md)
- Time decay — rep slowly returns toward neutral over very long time (months) if no interactions occur

### 5.3 Hostility cascades

Factions have **ally** and **rival** links with other factions. Rep shifts **leak** across those links at 25% rate. Helping Iron Concord gives small negative rep with Free Worlds Congress (their rival).

This is the mechanical implementation of "you can't please everyone."

## 6. Quest authoring guidelines

For the writing team. Every quest passes these filters:

### 6.1 The four-question test

Every quest must clearly answer:

1. **Who wants this?** A specific named NPC with motivation.
2. **Why now?** A world-state reason this couldn't be done last week or won't matter next week.
3. **Who opposes it?** A named rival, an obstacle faction, or an environmental threat.
4. **What changes if I do it?** A concrete world-state or relationship shift the player can see.

If any answer is "the quest-giver just says so," rewrite.

### 6.2 Quest rewards

Every completed quest gives at minimum:
- Credits proportional to difficulty
- Faction rep with the quest-giver's faction

Most also give:
- Items (weapons, modules, consumables)
- Faction rep with allied factions
- Codex entries (lore)
- Very rare: unique dialogue unlocks, companion recruitment paths

Bad rewards (don't ship): "5 credits and a generic potion." Every reward must be something the player would actually pick up.

### 6.3 No fetch quests without context

A "go fetch X" mission must be wrapped in a specific human reason. "I need this crate because my daughter is sick on the mining station" beats "go get this crate." Black Star's writing voice (see narrative bible §8) makes this easy.

## 7. Faction operation simulation

### 7.1 Operations tick

Each in-game day, factions advance their operations:

```python
for faction in all_factions:
    for operation in faction.operations:
        progress = operation.base_progress_per_day
        progress += operation.player_contribution_this_tick
        progress += operation.ally_support
        progress -= operation.rival_interference
        operation.progress += progress

        if operation.progress >= operation.stage_goal:
            advance_stage(operation)

        if operation.completed:
            apply_world_state_changes(operation)
```

Operations tick continues even when the player is not engaged. An ignored Iron Concord operation to reclaim Kepler will progress slowly on its own; the player just won't get the rewards of helping.

### 7.2 Visible consequences

When an operation completes, the player sees:
- News broadcast in station newsfeeds ("Iron Concord announces retaking of Kepler-3")
- Galaxy map updates (territory colors shift)
- Faction standings rebalance
- New operations spawn (success enables ambition)
- Rival factions may launch counter-operations

Invisible consequences are also tracked in the faction state but surface over time via rumors.

## 8. Writing-system integration

### 8.1 Dialogue system

Quests use the dialogue system from the narrative bible. Key features:

- Branching lines with player choice (2–4 options per beat)
- Speaker names + portraits
- Tone indicators in choices (friendly / cautious / aggressive / evasive)
- Skill-gated options (persuasion, intimidation, tech, faction rep)
- Companion interjections — companions weigh in based on their loyalty and beliefs

### 8.2 Codex integration

Every quest, every faction operation, every major event writes entries to the **Codex** — a searchable in-game encyclopedia. This is how the player keeps track of the sandbox's state.

## 9. Scope levers

If quest/faction scope threatens the timeline:

1. **Reduce faction operations to 3 per faction.** Still alive, less dynamic.
2. **Cut through-line length from 5–8 stages to 3–4.**
3. **Drop one faction through-line entirely** — Verdant Church is the most self-contained and could ship post-launch.
4. **Quest template count from 300 → 150.** Players see more repetition earlier.
5. **Drop faction operation simulation.** Operations become scripted sequences the player triggers; no autonomous progress.
6. **Cut the Central Mystery endgame** — final boss replaced with a "choose your ending" screen at a point-of-no-return. Worst lever, last resort.

## 10. Open questions

1. **Can the player decline a quest and come back to it, or does declining close it?** Permanent close-outs feel more consequential; re-opening is friendlier. *Owner: Design Lead. Resolve by: VS complete.*
2. **Do completed quests clutter the mission board visually?** They should collapse into a "completed" section. *Owner: UX. Resolve by: M6.*
3. **How do faction operations compete for the same quest-giver NPC?** If two factions both want to use the same captain as a quest-giver, who wins? *Owner: Systems Designer. Resolve by: Alpha 1.*
4. **Does the player's reputation leak affect companions from that faction?** A Sable Varn recruited at high Iron Concord rep may defect if rep drops. *Owner: Design Lead. Resolve by: Alpha 2.*
